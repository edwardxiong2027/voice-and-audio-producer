# Voice & Audio Producer

Prepare scripts and production notes for speech or sound generation with pronunciation, timing, and accessibility checks.

**Author:** Edward Xiong  
**Format:** Portable Agent Skill (`SKILL.md`)  
**Updated:** October 6, 2026

## Use it

Copy `SKILL.md` into an agent skill directory supported by your tool, or paste the starter prompt into a chat model and replace the bracketed inputs. The instructions are model-agnostic.

## What it does

Generating narration, a podcast segment, or a sound concept.

## Workflow

1. Write for the ear with breath-sized phrases.
2. Mark pronunciation and emotional shifts.
3. Keep dialogue and sound design distinct.
4. Check rights, disclosure, and accessible transcripts.
